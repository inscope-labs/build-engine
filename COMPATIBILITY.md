# Compatibility

Which version of the abstract castiel framework each engine release implements. The value is recorded in
`template/engine/ENGINE.json` (`implements_abstract`) and shipped inside the artifact. A release build
(`release/verify.sh --release`) fails while it is `UNSET`.

| Engine | Abstract castiel | Notes |
|---|---|---|
| 0.5.0 (unreleased) | UNSET | record the abstract version before the first release |
